# Support Triage Template

This template is intentionally broad. It helps collect information but does not contain concrete
repair steps for specific infrastructure failures.

## Questions to Ask

- Which customer or environment is affected?
- When did the problem start?
- Was there a recent deployment or configuration change?
- Is the impact constant or intermittent?
- Are there screenshots, logs, request ids, or dashboard links?

## Initial Notes

Summarize the symptom, affected service, known timeline, current owner, mitigation status, and
next update time. Attach evidence and avoid guessing before a domain-specific runbook is reviewed.
